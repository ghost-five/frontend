# Тестовый стенд

Папка нужна только для проверки игры на своей машине. На сайт она не выкладывается, игре не требуется.

Боевой Supabase просит подтверждать почту, поэтому сетевая часть проверяется на подмене: `mock-supabase.js` выдаёт клиент с тем же набором методов, но держит всё в `localStorage` браузера. Две вкладки одного окна становятся двумя игроками: `?as=1` и `?as=2`.

## Как запустить

```
node tools/stand.mjs
```

Стенд собирает копию игры в `tools/.stand` (подменяя `vendor/supabase.js` моком и `config.js` заглушкой) и слушает http://localhost:8778. Открывайте http://localhost:8778/?as=1 и http://localhost:8778/?as=2 — это два разных игрока.

Сценарии ходят на тот же адрес, поэтому стенд должен быть запущен в соседнем окне терминала:

```
node tools/scenarios/play.mjs       # партия с другом по сети, от приглашения до победы
node tools/scenarios/cancel.mjs     # отмена отправленного хода
node tools/scenarios/rewind.mjs     # перемотка ходов назад
node tools/scenarios/archive.mjs    # архив локальных партий и просмотр
node tools/scenarios/five.mjs       # пять в ряд против бота
node tools/scenarios/menu.mjs       # меню действий по правому клику
node tools/scenarios/anchors2.mjs   # два якоря, возврат и перемещение
node tools/scenarios/medal.mjs      # таблица лидеров, рейтинг и медали
```

Каждый сценарий запускает настоящий Chrome и водит его через `cdp.mjs`: `launch`, `newTab`, у вкладки `goto / eval / screenshot / size / theme / logs`. В конце печатает, что проверил, и кладёт скриншоты рядом. Chrome запускается с отдельным профилем, ваш обычный не трогается.

## О чём помнить

- Почти каждый сценарий начинается с `localStorage.clear()` и ставит `{hold: 0}` в настройки — иначе каждый ход ждёт паузу перед подтверждением.
- Мок не проверяет права доступа и рассылает изменения через событие `storage`, поэтому доходят они медленнее настоящего Realtime. Отсюда щедрые ожидания в сценариях.
- Рейтинг в моке считается упрощённо: Эло живёт в базе (`report_result`), проверять его по-настоящему можно только на боевом Supabase.
