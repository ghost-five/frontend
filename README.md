# Призрачная пятёрка: онлайн-версия

Игра «четыре или пять в ряд» с тайными ходами, короткой памятью, якорем, выстрелами, захватом пар и временем на ход. Длина ряда выбирается в правилах партии: четвёрка собирается заметно быстрее. Нужен бесплатный проект Supabase: он хранит аккаунты, друзей и партии.

**Разделы игры**

Пока игрок не вошёл, он видит только страницу входа. После входа сверху появляются четыре раздела:

| Раздел | Что внутри |
|---|---|
| **Игра** | Партия с ботом или вдвоём на одном устройстве, правила партии, журнал ходов, свёрнутая карточка с фишками |
| **По сети** | Друзья, приглашения, список партий, правила для новой партии |
| **Лидеры** | Рейтинг всех игроков, победы и поражения |
| **Вид** | Цвет и форма фишек (своих и соперника), светлая или тёмная тема |
| **Профиль** | Ник, смена пароля, выход |

Правила игры открываются кнопкой **«Как играть»** в правом углу верхней панели.

**Что умеет сетевая часть**

- Регистрация по нику, email и паролю с подтверждением почты, вход, восстановление пароля, смена ника и пароля.
- Друзья по нику: заявка, принять или отклонить, удалить из друзей.
- Партия с другом: нажимаете «Играть» рядом с ним, у друга появляется приглашение «Играть / Отказаться».
- Партия по ссылке для тех, кого нет в друзьях: код из 6 символов и ссылка.

Вся настройка занимает около 20–30 минут.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html`, `styles.css`, `app.js`, `engine.js` | Сама игра |
| `config.js` | Адрес вашего проекта Supabase и ключ. **Его нужно заполнить** |
| `vendor/` | Библиотека Supabase, лежит локально, чтобы не зависеть от сторонних CDN |
| `supabase.sql` | Таблицы, функции и правила доступа для базы |

## Шаг 1. Создайте проект Supabase

1. На [supabase.com/dashboard](https://supabase.com/dashboard) нажмите **New project**.
2. Придумайте имя, например `ghost-five`, и пароль базы (сохраните его, но игре он не нужен).
3. Регион выберите **Central EU (Frankfurt)**: он ближе всего к России.

## Шаг 2. Создайте таблицы

**Если игра у вас уже работает**, всё равно выполните `supabase.sql` заново: в нём появились рейтинг, таблица лидеров и защита от накрутки. Старые данные скрипт не трогает.

1. В меню слева откройте **SQL Editor** (иконка `>_`) → **New query**.
2. Откройте `supabase.sql` в Блокноте, скопируйте всё и вставьте в редактор.
3. Нажмите **Run**. Должно появиться `Success. No rows returned`.

Если Supabase спросит про «destructive operations», подтвердите: скрипт только пересоздаёт свои правила и функции, ваши данные он не удаляет.

**Если вы уже запускали прошлую версию файла**, просто выполните новую так же: она обновит базу и сохранит партии.

## Шаг 3. Впишите адрес и ключ в `config.js`

1. Нажмите кнопку **Connect** вверху страницы проекта (или **Project Settings → API Keys**).
2. Скопируйте **Project URL** (вида `https://abcd1234.supabase.co`) и публичный ключ: **publishable key** (`sb_publishable_…`) или, если его нет, **anon key**.
3. Откройте `config.js` и замените заглушки:

```js
window.GHOST_CONFIG = {
  supabaseUrl: 'https://abcd1234.supabase.co',
  supabaseKey: 'sb_publishable_...'
};
```

Секретный ключ (`service_role` / `sb_secret_…`) сюда **не вставляйте никогда**.

## Шаг 4. Проверьте настройки входа

Откройте **Authentication → Sign In / Providers** (в некоторых версиях панели **Providers → Email**):

- **Email** включён.
- **Confirm email** включено: игроки подтверждают почту кодом из письма.
- **Minimum password length** можно поставить `8`: игра и так требует не меньше 8 символов.

## Шаг 5. Настройте отправку писем через Яндекс

Встроенная почта Supabase шлёт письма только участникам вашей команды в Supabase и не чаще 2 в час, поэтому друзьям письма не придут. Нужна своя почта.

**В Яндексе:**
1. Откройте [id.yandex.ru](https://id.yandex.ru) → **Безопасность** → **Пароли приложений** → создайте пароль для **Почты**. Скопируйте его: он показывается один раз.
2. В Яндекс Почте откройте **Настройки → Почтовые программы** и разрешите доступ по IMAP с паролями приложений.

**В Supabase:** откройте **Authentication → Emails → SMTP Settings**, включите **Enable custom SMTP** и заполните:

| Поле | Значение |
|---|---|
| Sender email | ваш адрес на Яндексе, например `ghost.five@yandex.ru` |
| Sender name | `Призрачная пятёрка` |
| Host | `smtp.yandex.ru` |
| Port | `465` |
| Username | тот же полный адрес |
| Password | пароль приложения из пункта 1 |

Для Mail.ru: хост `smtp.mail.ru`, порт `465`, пароль для внешнего приложения из настроек безопасности Mail.ru.

С этой настройкой Supabase отправляет до 30 писем в час, лимит меняется в **Authentication → Rate Limits**.

## Шаг 6. Поправьте тексты писем

Откройте **Authentication → Emails → Templates**. Нужны два шаблона: в обоих должен быть код `{{ .Token }}`, потому что игра просит ввести его. Ссылка в письме тоже работает.

**Confirm signup** (подтверждение регистрации)

Тема:
```
Код подтверждения «Призрачной пятёрки»: {{ .Token }}
```
Текст (вкладка Source):
```html
<h2>Ваш код: {{ .Token }}</h2>
<p>Введите его на странице игры, чтобы подтвердить email.</p>
<p>Или просто нажмите <a href="{{ .ConfirmationURL }}">подтвердить и войти</a>.</p>
<p>Если вы не регистрировались в «Призрачной пятёрке», ничего делать не нужно.</p>
```

**Reset Password** (восстановление пароля)

Тема:
```
Код для смены пароля: {{ .Token }}
```
Текст:
```html
<h2>Ваш код: {{ .Token }}</h2>
<p>Введите его на странице игры вместе с новым паролем.</p>
<p>Или нажмите <a href="{{ .ConfirmationURL }}">сменить пароль</a>.</p>
<p>Если вы не просили сменить пароль, просто удалите это письмо.</p>
```

## Шаг 7. Опубликуйте сайт

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите туда **всю папку** `ghost-five-online` (с заполненным `config.js`).
3. Появится адрес вида `https://random-name-123.netlify.app`. В **Site configuration → Change site name** его можно заменить на понятный.

Чтобы обновить игру, откройте сайт в Netlify → **Deploys** и перетащите папку ещё раз.

## Шаг 8. Укажите адрес сайта в Supabase

Откройте **Authentication → URL Configuration**:

- **Site URL**: адрес вашего сайта, например `https://ghost-five.netlify.app`
- **Redirect URLs**: добавьте `https://ghost-five.netlify.app/**`

Без этого ссылки из писем поведут не туда (коды из писем будут работать и так).

## Шаг 9. Проверьте

1. Откройте сайт: сразу появится страница входа. Нажмите **Регистрация**.
2. Введите ник, email и пароль, затем код из письма.
3. Попросите друга зарегистрироваться и добавьте его по нику в разделе **По сети**.
4. Когда он примет заявку, нажмите **Играть** рядом с ним. У друга появится приглашение.

Зелёная точка рядом с кодом партии значит, что ходы приходят мгновенно. Если точка серая, игра всё равно работает и проверяет новые ходы каждые несколько секунд. Пока за столом нет второго игрока, партия опрашивает сервер чаще, чтобы начаться сразу после его прихода.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Онлайн-режим ещё не настроен» | Не заполнен `config.js` или на Netlify загружена старая папка |
| «Не получилось отправить письмо» или «Email address not authorized» | Не включён или неверно настроен свой SMTP (шаг 5). Подробности в **Logs → Auth** |
| Письмо не приходит | Проверьте «Спам», подождите пару минут. Логи отправки в **Logs → Auth** |
| В письме нет кода | Не обновлён шаблон (шаг 6) |
| «Код не подошёл» | Код устарел или уже использован: нажмите «Отправить письмо ещё раз» |
| «Регистрация в проекте выключена» | Включите регистрацию в **Authentication → Sign In / Providers** |
| Вход по коду из прошлой версии больше не работает | Нажмите «Забыли пароль?», получите код и задайте пароль. Аккаунт и партии сохранятся |
| Просит придумать новый ник | Старый ник не подходит под правила (3–20 символов без пробелов) |
| Сайт не открывает Supabase, вечная загрузка | Бесплатный проект засыпает после недели без активности: нажмите **Restore** в панели Supabase |
| Supabase недоступен из России | Можно поднять Supabase на своём сервере у российского хостера (self-hosted). Файлы игры те же, меняется только адрес в `config.js` |

## Как это устроено

- **Аккаунты.** Пароли хранит Supabase Auth, игра их не видит. Email других игроков не показывается нигде, только ники.
- **Друзья.** Заявки и дружба меняются только через функции базы: нельзя добавить себя другому в друзья без его согласия.
- **Отмена партии.** Пока не сделано ни одного хода, удалить партию может любой из двоих: правило доступа проверяет по сохранённому состоянию, что раунд первый и ходов нет. Законченную партию тоже может удалить любой участник, а создатель — любую свою. Из идущей партии выходят сдачей: её можно нажать и в списке «Мои партии», не открывая партию.
- **Приглашения.** Пригласить в партию можно только друга. Партию с приглашением видят и могут занять только вы и он. Партию по ссылке может занять любой зарегистрированный игрок, у которого есть код, пока стол свободен.
- **Тайные ходы.** Игрок отправляет на сервер только хеш своего хода. Когда оба сходили, каждый открывает свой ход, игра проверяет его по хешу и только тогда показывает результат.
- **Отмена хода.** Пока соперник выбирает, свой ход можно отозвать: на сервере остаётся пустой хеш, и для соперника это снова «ещё не сходил». Как только сходил он, ходы начинают раскрываться и отмена пропадает.
- **Время на ход.** Отсчёт у каждого свой и начинается с момента, когда игрок увидел свою очередь: общие часы потребовали бы сверки времени с сервером, а расхождение тут меньше задержки сети. Не успел подтвердить, но клетку уже выбрал — ход уходит туда; не выбрал ничего — ход пропускается.
- **Запас времени.** Общий резерв на партию, который тратится после основного лимита. Сколько секунд взято из запаса, игрок сообщает вместе с ходом, и это число входит в хеш тайного хода — иначе соперники разошлись бы в подсчёте.
- **Три пропуска подряд** — поражение. Счётчик хранится в состоянии партии и обнуляется любым сделанным ходом.
- **Якорь.** Не исчезает от времени и не сбивается выстрелом. Ставится на пустую клетку или на вашу фишку, которая уже стоит на поле; двигается на соседнюю клетку (стену на пути ломает) — это ход. Возврат в запас после пяти ходов хода не стоит: он отмечается галочкой и происходит вместе с обычным ходом.
- **Внешний вид.** Цвета и формы фишек хранятся только в браузере игрока: каждый выбирает, как выглядят обе стороны у него на экране, и на соперника это не влияет. Колонка `looks` в базе осталась от прежней версии и на отображение больше не влияет.
- **Рейтинг.** Считает сама база: функция `report_result` смотрит на сохранённое состояние партии, применяет формулу Эло (K = 24, старт 1000) и ставит партии отметку «учтена», чтобы очки не начислились дважды. Игрок не может подправить свой рейтинг: триггер `profiles_guard` пропускает такие правки только изнутри этой функции. Но состояние партии по-прежнему пишут сами игроки, так что рейтинг честен ровно настолько, насколько честны соперники.
- **Правила доступа** проверяет сама база (Row Level Security): ходить и менять партию могут только два её игрока, каждый только за себя.

## Проверить у себя на компьютере

Игре нужен адрес `http://` или `https://`: из файла `index.html` браузер не пустит её к Supabase. Поднимите простой сервер:

```
python3 -m http.server 8000
```

и затем откройте `http://localhost:8000`. Добавьте `http://localhost:8000/**` в Redirect URLs (шаг 8), если хотите переходить по ссылкам из писем.
